# 카톡 코칭 기준 (연애 코치 역할)

감정소 추천 답장 · 답장 채점 · 말투 학습 피드백이 따르는 기준. 프롬프트 원문은 `apps/relay/src/prompts/coaching.ts`,
채점 감점 규칙은 `apps/relay/src/prompts/score.ts`. 이 문서를 고치면 둘도 같이 고친다.

## 왜 만들었나 (2026-10-14)

- 내 말투를 학습한 뒤 채점이 "그 사람 말투와 같으면 OK"로 기울었다. 예: 상대 "오늘 저녁 뭐 먹었어?" → "나 오늘 ㅋㅋㅋ 김치찌개 먹었지 ㅋㅋㅋ"가 65~70점
- 원인: 채점 프롬프트에 "평소 말투(ㅋㅋ 등)로는 감점하지 않는다"는 규칙이 있었다
- 사용자 요청: 연애 코치로서 학습한 습관이 상대에게 안 좋게 보이면 짚어 주고, 밀당도 무조건 나쁜 것만은 아니니 구분할 것

## 원칙

1. **상대에게 맞춘다** — 상대가 짧게 쓰면 짧게, 길게 털어놓으면 성의 있게. 맞추는 기준은 상대이지 내 습관이 아니다
2. **받은 말에 먼저 반응** — 질문엔 먼저 답하고, 상대 말 · 감정을 받아 준 뒤 내 얘기 · 질문
3. **질문은 하나, 답하기 쉽게** — 질문 폭탄 · 장문은 심사받는 느낌
4. **ㅋㅋ · ㅎㅎ · 이모지는 양념** — 웃긴 지점 · 감정 살릴 곳에만. 문장마다 ㅋㅋ, 진지한 얘기에 ㅋㅋ, 한 메시지 이모지 3개 초과는 감점
5. **줄임말 · 무성의 단답(ㅇㅇ, ㅇㅋ) 남발 금지**
6. **짧은 답이 좋은 순간** — 기분 좋은 마무리, 상대가 바쁘거나 잘 때, 가벼운 농담, 여운 남기기
7. **건강한 텐션 조절(가벼운 밀당)은 괜찮다** — 마음을 한 번에 다 쏟지 않기, 즉답 · 매일 선톡 강박 없이 내 리듬대로,
   따뜻함이 바탕인 가벼운 장난 · 튕김, 좋은 분위기에서 먼저 마무리하고 다음을 기대하게 하기
8. **나쁜 밀당(조종)은 안 된다** — 일부러 읽씹 · 답장 미루기로 불안하게, 질투 유발, 떠보기, 죄책감 자극,
   냉온탕 반복, 이별 협박, 답장 재촉 · 집착. 채점 총점 35 이하 고정
9. **관계를 앞으로** — 분위기 좋을 때 구체적 제안(언제 · 무엇)
10. **관계 단계에 맞춘다** — 썸 가볍게 · 연애 중 자연스러운 애정 · 권태기 관심과 칭찬 · 이별 후 선 존중

7과 8의 경계: **상대가 내 마음을 의심하게 만들거나 불안하게 만들려는 의도**가 있으면 나쁜 밀당이다. 상대도 같이 웃을 수 있는 장난, 내 생활 리듬은 괜찮다.

## 점검 방법

- `npm run eval:coach` — 학습한 말투에 나쁜 습관이 섞인 사용자로 13개 답장을 2번씩 채점해 기대 구간 안인지 본다
  (8개는 프롬프트 예시와 비슷한 사례, 5개는 프롬프트에 없는 새 사례). 1회 약 10원
- `npm run eval:sim` — 연습 상대 말투(길이 · 이모지 · 말버릇 · 메모 언급) 점검
