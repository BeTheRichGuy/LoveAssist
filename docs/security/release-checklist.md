## 번들 검사 (배포 전에 다시 돌린다)

```bash
cd apps/mobile && npx expo export --platform android --output-dir ../../dist-check
```

생성된 `dist-check/_expo/static/js/android/*.hbc`에서 `sk-ant`, `ANTHROPIC_API_KEY`, `TOKEN_SECRET`이 0건이어야 한다.
(`dist-check`는 확인 후 지운다.)
